# 知序 V6.5｜学习页内的连续科学探索工作台（2026-11-05）
## 已确认边界
- 仅改 `apple-editions/ai-academy-v5/` 的课程学习内容（`.core-learning`）。**Dock、今天、资料、进度、设置、博士顶部面板、DeepSeek Sheet、路由、弹簧物理参数全部保留**。
- 继续保留 PFL 与 EvoWorld 两个科学实验、前测默认不选、独立预测、明确批准真实运行、证据观察、导师、二次对照、反思、迁移及完成；不删除已接入功能、不增加课程导航页面。
- 不改变 ScienceBridge、Original 科学引擎、V2 证据格式、BYOK 安全许可、刷新持久化边界。新可视化以 `snapshot().visualization` 的已有真实点和种子为唯一数据源。
## 方案取舍
1. 禁止「一页多张大圆角 AI 卡片」；采用**同一知识工作台**的轻层级：阶段标题、问题提示、实验画布、证据标注/对照、引导式下一步。大块以细分隔线和留白区分，仅主实验框使用适度圆角（10–14px）。
2. 在同一页中保留所有表单。通过排版/信息结构减少表单抢占主画面，避免必须的实验授权和反思被隐藏。
3. PFL 首个真实 SVG 轨迹增加**时间进度 Scrubber**：用真实点数组逐帧选点，游标/两条曲线真实点同步，缺失点明确显示无数据。拖动只改变可视游标，不运行科学引擎、不写 V2、不预选测验答案。保留已有真实点“正式选择”按钮（与导师接口链接）。
4. EvoWorld 保留原版分组柱状图和配对随机种子选择，在图表前给出观测挑战并突出模型内与现实的推断界限；不凭空生成世界动画。
5. 展开式「实验详情」保留 Run ID、全部真实指标和限制说明；默认减少视觉噪声。选中数据及第二次真实运行应明确标注真实证据。
6. 学习页内容进入采用轻微**transform-only 的 spring settle**，不将各段重新缩放/淡出或叠多个动画所有者。交互控件真实跟手且尊重系统减少动态效果。移动与桌面响应式、课程内局部运动不干扰外部成对页面平移。
7. 完成视图显示「原始预测 → 真正观察的证据 → 学生记录的反思 → 实际迁移判定」证据摘要；不生成不存在的表现结论。
