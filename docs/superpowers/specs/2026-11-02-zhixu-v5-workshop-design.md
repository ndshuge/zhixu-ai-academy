# 知序 AI V5｜学习工作室 × 科学实验室设计（2026-11-02）

## 目标与认可
用户选定融合方案：Apple Books 式安静、清晰的学习工作室 + Brilliant 式可操作科学实验室。评委从原参赛 URL 进入最新公开版本，三十秒理解核心价值并能完整走过「前测—预测—科学计算—导师解释—迁移—学习证据」。批准保留 V4 完整拷贝不变，另复制成 V5 独立源码进行施工；新 V5 经过测试发布后成为默认评委入口。原 URL 永不更改。

## 边界
- 唯一正式主仓库：`ndshuge/zhixu-ai-academy`；V5：`apple-editions/ai-academy-v5/`。
- V4 原版目录 `apple-editions/ai-academy-v4/` **不做任何改动**；R3 和 `original.html` 保留。
- V5 继续依赖 Original `learning.html` / 同源 ScienceBridge、版本 V2 localStorage；不修改题库、评分、API 授权、科学引擎以及真实 AI 密钥逻辑。
- 原首页 `/zhixu-ai-academy/` 默认路由 V5，兼容 `?judge=1`、UTM、hash；显式 `?edition=v4`、`?edition=r3`、`?edition=original` 应保持历史访问。
- 小东西版本中心添加 V5 当前版，保留 V4 / R3 / Original。
- 避免仪表盘滥堆、伪造学习效果、伪造联网 AI；Safari 光学保留诚实的 blur fallback；遵循 reduced motion。

## 方案权衡
A（单纯课程书架）阅读舒服但评委看不到实验；
B（纯科学实验）演示强但弱化长期私人教师；
**采用融合 A+B**：首屏用一个真实学习问题承载「开始私人教师」与「立即探索实验」两种入口，学习页中概念—原版题库—实验参数和图形—博士对话贯通，数据档案不喧宾夺主。

## UI/行为
- 首页重新组织：顶部「知序学习工作室 / 科学实验」标签；主 Hero 一张主任务卡；下方两个路径入口「跟着知序博士学习」「直接探索实验」；小型、真实 3/4 步方法条；历史学习概览放在次层级，未产生的次数显示真实 0。
- 桌面空目录栏减少闲置；手机保留无图标重影的五栏语义导航，突出中央学习入口；卡片触控面积 >44px，无自动弹出键盘。
- 科学实验专区可直接预览真实公式计算的 Logistic 对照曲线和 EvoWorld 入口，参数示例不冒充后端实测、仅标注演示值；正式运行仍使用原版 ScienceBridge。
- 导航共享高亮弹性/按压；主题色克制；正文过渡采用轻微交错与透明度而非整页冻结快照；支持系统 reduce-motion。
- 博士状态需清楚提示规则导师 vs 已验证模型，不能假装未配置时自由聊天。
- 不因历史零样本宣称能力/掌握提升。

## 验收
1. 原 V4 文件内容哈希不变、独立 V5 可加载。
2. 首页可直接进入实际教学的前测和科学实验两个分支；V5 科学桥可连接。
3. 所有评委、历史版本与查询参数路由测试通过；CI 构建必须包含 V5 所有 assets。
4. node 全测试、前端语法和安全文件名校验；Chrome/Windows WebKit 的静态主流程至少本机回归，移动端截图人工检查；真 iPhone Safari 未测要说明。
5. 推送前 fresh fetch 并审查路径差异；CI/Pages 发布和实际原链接跳转均检查；否则保持旧 V4 为正式版。
