## 实施边界
- **底部 Dock 的 DOM、玻璃材质、渐变、选中态、按钮位置与原有进/退场物理参数完全冻结**；任何增强都仅限 `#screen`、`#doctor-panel`、`#dialog-layer` 里的 UI。
- 不把参考的旧网站 `python.html` 覆盖 V5 `v4.js`、`views.js`、`index.html`。以当前 `02f04cc` UI 发布基线、独立功能核为准。
- 共享元素 Magic Move 在适配成稳定的跨页面可追踪配对前，不假称所有按钮已达到原生 Apple 水准。严格尊重 `prefers-reduced-motion`、禁止截取 Dock 的 View Transition 快照、保护原版 PFL/Evo 科学数据和用户 BYOK Key。
- 路由支持四主页面 + 设置工具页；不恢复已经删除的 Courses 独立路由；设置是顶部工具操作，不加入已冻结 Dock。
- 弹层关闭必须有延迟 DOM 卸载、可被重复关闭保护、恢复原触发焦点、Escape/取消、背景不误触及输入框密钥及时清除。
- 验收通过 Node、Edge、WebKit 的真实页面状态测量与截图检查；WebKit ≠ iPhone Safari 真机。
