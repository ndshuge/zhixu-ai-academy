输入管理员口令查看配置。密钥永远不显示。

交付给学校的是什么？

1自己的模型和费用账户。学校决定服务商、模型及消费限额；无需给学生分配原始 API Key。
2独立的科学教学引擎。Physics Frontier Lab 与 EvoWorld 提供真实计算，不依赖模型凭空生成数值。
3可审计的教学流程。学生先预测，再实验、解释、复测；模型不能直接修改科学结果。
4模型失效时回退。配额用尽或服务异常，仍可进入本地规则引导，不影响原实验运行。

部署边界

这是Windows 本机单校验证版，尚不具备学校生产环境所需的统一身份认证、租户隔离、密钥保险库、审计日志和 TLS 反向代理。不能因为能填入 Key 就宣称已可直接服务全校。

演示策略：本机使用你自己的模型账户完成一条教学流程；正式部署时由校方管理员替换为校方的 API。
