# 知序 AI 学院 GitHub Pages 科学与 AI 交互版

这是原版 AI 学院的网页、11 张博士角色图和相关资源的公开浏览器版，不是从零做的缩水 UI。

可实际运行：浏览器真实 Logistic 数学计算、原 EvoWorld 引擎配对实验、学生独立前测和迁移、
确定性题库评分与错因候选、学生明确批准的第二轮单变量实验、固定安全拒绝示例、学习证据。
连接真实 AI：用户在当前标签页输入自己的 DeepSeek Key；通过真实连接测试以后，
经每次明确授权，原版导师追问和实验规划按钮可调用官方模型。科学结果始终由科学计算产生。

重要限制：
* GitHub Pages 无法运行原始 Node.js 服务器，这里使用浏览器本地兼容层。
* 完整的校园账户、服务端持久存储、防作弊评分及学校管理后台仍需要真正的后端。
* 浏览器内公开题库包含评分规则和标准答案，不可声称防作弊。
* API Key 仅保存在当前标签页内存，不写入 GitHub 或 localStorage；公共设备和扩展程序仍可能读取。
* 固定安全案例不是遭遇过的真实模型攻击，测试情境不是有实际真人学习成效的数据。
* Logistic 与 EvoWorld 均明确使用 browser 引擎标签，不假称原 PFL 服务端同版本。
原始完整服务端工程仍保留在本机，未上传凭据和私密日志。
