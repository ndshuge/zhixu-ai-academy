## 已实现（本机V0.4学习试点原型；保留V0.3原功能）
- PFL真实数值内核：初值敏感性、非线性迭代，显示真实曲线和诊断。
- EvoWorld原生实验接口：两种合作条件、每条件两个独立种子、200 tick 的真实配对实验。样本很小，明确为方法演示。
- 强制学生事前预测、运行、看结果、规则/可选AI反思反馈、主动答迁移题，再安排下一轮单变量实验。
- 导出/清空学习记录：默认仅浏览器localStorage，不自动上传。
- 在服务器中保留短时运行记录，防止客户端伪造数值发给导师。
- 可选远程LLM（兼容chat/completions接口），无密钥时界面明确显示规则引导。
- 源PFL通过只读编译打包，记录bundle/依赖SHA256；EvoWorld从原工程只读复制11个科学模块构成带文件哈希的固定快照，AI学院**不再运行时引用原EvoWorld源文件**。两项目均不被修改。
- V0.3新增科学工具注册、单变量实验方案预览、学生重新预测与人工批准、批准后实际运行和原实验前后比较；计划单次有效、期限15分钟、教学链最多5轮。当前规划模式为 `rules`，不是自主大模型工具调用。
